
# Serviq

Smart Field Service Management Platform.

## Overview

Serviq is a multi-tenant web and mobile
application for technical maintenance companies.

## Technology Stack

- Web: Next.js + TypeScript
- Mobile: React Native + Expo
- API: NestJS + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Cache/Jobs: Redis + BullMQ
- Infrastructure: Docker

## Languages

- French
- Arabic (RTL)

## Development

The project follows a modular monolith
architecture and incremental delivery.
